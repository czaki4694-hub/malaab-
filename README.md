# ملعب

تطبيق ويب (PWA) فيه كرة القدم، الأفلام، المسلسلات، القنوات والأخبار. ملف واحد (`index.html`) بلا تثبيت ولا برمجة.

## النشر على GitHub Pages (من الهاتف أو الكمبيوتر، بلا أوامر)
1. سجل فـ github.com ثم **New repository** وسميه `malaab` (خليه Public).
2. **Add file ← Upload files** وارفع كل ملفات هاد المجلد (`index.html` و`manifest.webmanifest` و`sw.js` و`icon.svg` و`.nojekyll`) ثم **Commit changes**.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save**.
4. بعد دقيقة، التطبيق غيكون فـ `https://اسم_حسابك.github.io/malaab/`.
5. فالهاتف: افتح الرابط ثم **إضافة إلى الشاشة الرئيسية**.

## التعديل
- افتح `index.html` فـ GitHub واضغط على أيقونة القلم.
- القنوات: دور على `const CH=[` وزيد سطر `["الاسم","النوع","رابط الموقع الرسمي"]`.
- الأفلام والمسلسلات والأخبار والمباريات: `MOV` و`SER` و`NW` و`MT` فنفس الملف.

## ملاحظات
- البيانات الحالية **تجريبية**. الربط بـ API حقيقي كيحتاج Backend (شوف خطة المرحلة 1 و2).
- ما فيه حتى رابط بث. المستعمل كيلصق روابط **عندو حق بثها** (مصادر رسمية أو محتواه). بث محتوى بلا ترخيص ممنوع وكيعرض الحساب للحذف.
- أسماء القنوات ملك لأصحابها، والتطبيق ما كيدعي أي شراكة معاهم.
